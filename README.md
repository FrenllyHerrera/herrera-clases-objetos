**Descripción del programa**
Este es un programa de consola desarrollado en C# para la tienda TecnoPunto. Su objetivo es registrar productos en un inventario, validando que los datos ingresados sean correctos y calculando automáticamente el valor total en existencia de cada producto.

***Datos de Entrada***
El programa solicita al usuario por teclado los siguientes datos para 3 productos:
Código, nombre, precio y cantidad.

***Datos que procesa***
**Validaciones:** El nombre no puede estar vacío, el precio debe ser mayor a 0 y la cantidad no puede ser negativa. Si hay errores, el sistema avisa y corrige el dato.
**Cálculo:** Calcula el ValorTotal multiplicando el precio por la cantidad.

***Datos de Salida***
El programa imprime en consola un cuadro con la información de cada producto (Código, Nombre, Precio, Cantidad y Valor Total) y al final muestra el valor total sumado de todo el inventario.
